# 2026 DOT CALENDAR

2026년의 일정을 날짜별로 기록하고 관리할 수 있는 달력형 To Do 서비스입니다.

하늘색을 메인 컬러로 사용하고 도트 패턴, 선명한 검정 외곽선, 하얀 강아지 캐릭터를 조합해 귀여운 Y2K 문구류 느낌으로 디자인했습니다. 이모지와 그라디언트는 사용하지 않았으며, 전체 인터페이스에는 Pretendard 폰트를 적용했습니다.

## 주요 기능

- 2026년 월별 달력 보기
- 이전 달과 다음 달 이동
- 오늘 날짜 바로가기
- 날짜를 선택해 할 일 추가
- 할 일 완료 및 미완료 상태 변경
- 개별 할 일 삭제
- 완료한 항목 일괄 삭제
- 날짜별 할 일 미리보기
- 월별 완료 현황 표시
- 브라우저 새로고침 후에도 할 일 유지
- 데스크톱 한 화면 맞춤 레이아웃
- 모바일 및 태블릿 반응형 지원

## 사용 방법

1. 달력에서 할 일을 기록할 날짜를 선택합니다.
2. 오른쪽 `DAILY TO DO` 영역에 할 일을 입력하고 `추가` 버튼을 누릅니다.
3. 체크박스로 완료 상태를 변경합니다.
4. 필요 없는 항목은 `삭제` 버튼으로 지울 수 있습니다.
5. 완료 항목이 있으면 `완료한 항목 지우기` 버튼으로 한 번에 정리할 수 있습니다.

## 데이터 저장

할 일은 브라우저의 `localStorage`에 저장됩니다. 별도의 계정이나 서버 없이 현재 브라우저에서 사용할 수 있으며, 같은 기기의 같은 브라우저에서는 새로고침하거나 다시 방문해도 기록이 유지됩니다.

브라우저 데이터를 삭제하거나 다른 기기 또는 브라우저에서 접속하면 기존 할 일은 표시되지 않습니다.

## 기술 구성

- HTML5
- CSS3
- Vanilla JavaScript
- Pretendard Web Font
- Local Storage API

외부 프레임워크나 데이터베이스 없이 정적 웹 애플리케이션으로 구성했습니다.

## 프로젝트 구조

```text
.
├── README.md
└── dist
    ├── index.html
    ├── styles.css
    ├── script.js
    └── white-puppy.png
```

## 로컬 실행

`dist` 폴더를 정적 웹 서버로 실행한 뒤 브라우저에서 접속합니다.

```bash
python3 -m http.server 4173 --directory dist
```

실행 후 다음 주소를 엽니다.

```text
http://localhost:4173
```
